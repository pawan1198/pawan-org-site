** India Trade Data Analysis Pipeline

*Status:* Completed | *Tools:* R, data.table, ggplot2

A comprehensive pipeline covering *8-digit HS code* level import/export data
from 2018–2026, sourced from DGCI&S. Produced 12 publication-quality plots
with a custom ggplot2 theme, covering:

- Commodity-level trade balances over time
- Top trading partners by HS section
- Import concentration risk using Herfindahl-Hirschman Index (HHI)
- Year-on-year growth heatmaps by commodity group

** Petroleum Data Analysis (NITI Aayog ICED)

*Status:* Completed | *Tools:* R, ggplot2, PPAC, RBI data

Full pipeline built from NITI Aayog's ICED portal data, producing *10 charts*
and a master ~.rds~ file. Included recommendations for dataset enrichment from
PPAC and RBI sources. Key outputs:

- Crude oil import price trends
- Refinery throughput vs domestic consumption
- Fuel price pass-through analysis
